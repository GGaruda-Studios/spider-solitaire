# Golden Garuda Studios

The organisation site, serving the legal pages for our published apps.

Live at <https://goldengarudastudios.github.io/>.

## Contents

- [Privacy Policy](privacy-policy.html) — Spider Solitaire Classic
- [Terms of Service](terms-of-service.html) — Spider Solitaire Classic

Google Play requires both as live, publicly reachable URLs before a listing can
be submitted, and they must stay reachable for as long as the app is listed. A
`github.io` address is used rather than a custom domain precisely because it has
no renewal to forget: a lapsed domain would take the policy offline and put the
listing in violation.

Each app's own repository holds the source of these pages under `docs/`. Edit
there, copy here, push.
